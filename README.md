# An Automated Mechanism for Obligatory Report Publication and Discovery

Some regulations require a regulated entity to publish reports about their regular operations.

For example, NYC's [Local Law 144 of 2021](https://www.nyc.gov/site/dca/about/automated-employment-decision-tools.page)
requires publication of reports derived from
audits of automated decision-making tools used during employment decisions.

Despite the regulatory requirement of making these audits visible and available,
it has been [challenging](https://dl.acm.org/doi/10.1145/3715275.3732004) to even find these reports.

This specification attempts to create a standard
that would simplify the discovery of self-published reports
associated with any comparable regulation.

You might want to look at [the editor's copy](https://dkg.github.io/reports.json).
